## Overview
This page provides access to the final project files used in the development of the Audio and Alert subsystem. These files include the complete MPLAB X code project and a full KiCad project archive containing the schematic, PCB layout, and Gerber files. All resources are stored in the GitHub repository for long-term version control and accessibility.
<br>

## Final MPLAB X Project (ZIP)
The complete MPLAB X project used for the final subsystem implementation is available below. This archive contains all source files, header files, configuration settings, and project metadata required to rebuild or modify the code.

Download the final MPLAB X project:  
[*Click here to download*](https://raw.githubusercontent.com/rmwirt-source/rmwirt-source.github.io/main/docs/09-Resources/SpeakerSubsystem_V1.zip)
<br>

## Full KiCad Project Files (ZIP)
This ZIP includes the entire KiCad project for the subsystem, containing the schematic, PCB layout, symbols, footprints, and the Gerber files used to manufacture the PCB. This single archive contains everything needed to review, modify, or reproduce the hardware design.

Download the full KiCad project:  
[*Click here to download*](https://raw.githubusercontent.com/rmwirt-source/rmwirt-source.github.io/main/docs/09-Resources/SchematicDesign_RW.zip)
<br>
